# 历史文档归档

本目录保存旧版 LPC、efun 和 apply 文档，仅供历史查阅，不作为当前开发依据，也不随驱动升级同步维护。

- 查询当前 efun/apply 的签名、行为和限制，必须查阅所用 FluffOS 版本对应的 [驱动文档](../fluffos/docs/)或[驱动源码](../fluffos/src/)，有疑义时以实现为准。
- 本 MUD 的架构、实现和开发规范见 [`docs/`](../docs/README.md)；文档随开发同步补充完善，不安排专项全量补齐。
- 面向游戏用户的玩法说明、命令用法与操作帮助统一放在 [`help/`](../help/)。
