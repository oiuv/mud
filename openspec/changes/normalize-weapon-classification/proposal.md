# Proposal

## Why

历史代码将长枪归为棍、部分斧归为锤，武器继承、基本技能和特殊武学随之错配。物品数据化之后应进一步建立合理的武器分类，而不是继续复制这些错误；本轮是明确授权的玩法分类修正，不是要求行为逐项不变的普通数据迁移。

## What Changes

- **BREAKING**：以 `SPEAR` / `spear` 作为枪类正式接口，替代 `FORK` / `fork`。长枪、钢叉及经核定的同类长兵器使用枪类；实际火枪不按名称机械归类。
- **BREAKING**：中平枪法及圣骑士戟武学改用基本枪法；盘根错节斧、盘古七式、雷霆斧法改用基本斧法。同步武器、NPC、学习、练习、激发、绝招和特殊武器回调，不扩大这些武学的跨类兼容。斧与锤分别采用利器劈砍和钝击的动作、伤害类型，不借此重做伤害数值。
- 新增共用的撼山锤法 `hanshan-chuifa`，支持基本锤法与招架。常金鹏、童百熊、赵鹤分别保留西瓜锤、铜锤、雷震挡，以新锤法替换原盘古七式配置，同步招架、绝招和既有教学入口；保留 NPC 原等级，不为三人分别创建武学，也不让盘古七式兼容锤系。
- 全金发保留钢制杆秤及基本棍法，以已有的采燕功 `caiyan-gong` 替换中平枪法，棍法与招架激发同步，仍为 65 级；保留原轻功和其他配置，不新增专属武学或主动绝招。
- 武器定义与路径一起归入正确类别，例如 `/d/items/club/bintie_qiang` 改为 `/d/items/spear/bintie_qiang`，`/d/items/hammer/kaishan_fu` 改为 `/d/items/axe/kaishan_fu`。唯一数据定义、简洁 ID 和全部实际调用同步，不保留旧路径壳、转发或混合类别处理程序。
- 对已迁移普通武器数据核对同名同用途的重复品种；没有实际设计必要的细微重量、价格或伤害差异允许统一，形成一个合理基准、一份定义、一个规范身份。逐项记录原值、目标值与理由，不机械取最高属性；必要的特殊功能、任务身份及装备档次仍区分。
- 师父按实际教授武学提供相应基本技能：只有枪法的以基本枪法替换原基本棍法；兼教棍法的保留棍法并提供枪法。斧法教学同步归正，不借此调整贡献、内力等无关条件。
- 补齐基本枪法的公共学习途径：陈有德允许老玩家缴纳 500 铜钱补学基本枪法至 80 级，其他教学规则不变；新增《枪法入门》，由陈有德按其他入门秘籍的规则出售，沿用现有书籍与研读机制，不扩展为书籍批量重构。
- 玩家自行学习所需的基本武功或新锤法并重新激发；不转换、补偿、删除已有技能，不自动改写玩家的等级、熟练度、激发或绝招领悟记录，不自动赠送撼山锤法，不添加登录迁移。
- CLUB 与 STAFF 保留两类独立武功，本轮不合并、不设计新的强弱差异；后续武学按实际用法和所属体系选类。
- 记录特殊兵器与武学错配的逐项处置、改动清单、回归依据和玩家更新说明；旧物品路径可能仍存在于存档，单独揭示部署风险，不暗中增加存档处理或兼容代码。

## Capabilities

### New Capabilities

- `weapon-classification`: 武器形制与武学的合理分类、枪类接入、共用撼山锤法及关联教学与战斗一致性，以及玩家技能不迁移的明确边界。

### Modified Capabilities

- `game-object-families`: 区分忠实数据迁移与明确批准的分类修正；允许后者调整类别及直接关联行为，但不扩散到无关数值、功能或未选对象。
- `game-object-definitions`: 明确批准的武器规范化允许先消除无必要的细微差异，再归并为唯一品种，不以历史数值必须逐字相同阻止合理统一。

## Impact

- `include/weapon.h`、`inherit/weapon/`、`d/items/`；相关 `/clone`、`/b` 和 `/d` 实体武器只做必要类别修正，不恢复这些目录的批量数据化。
- `kungfu/skill/`、`kungfu/class/`、相关 NPC、技能命令、中文技能名称和物品存取入口；必要时补齐基本枪法与基本斧法的命令登记。
- `clone/book/basic-spear.lpc` 与 `d/city/npc/chen.c` 的备货及基本枪法补学入口；复用既有 BOOK、买卖、学习与研读机制，不修改其他秘籍或新增书籍框架。
- 现有物品校验工具、驱动回归和文档，新增分类差异预期而不改写旧快照。开发规范、维护台账、玩家帮助与 `help/changelog` 随实现同步。
- 不修改 mudcore、驱动或权限框架；不读取、转换或写入正式玩家、商店、NPC 存档。旧物品持久路径的上线处置与代码验收分开，不宣称直接更新即可无损恢复旧记录。

## Non-goals

不继续普通物品迁移或 NPC 数据化；不建设通用武器插件框架、技能转换器、旧接口兼容层、火器系统或棍杖差异化战斗系统。不因历史分类混乱顺带重做全服战斗平衡。
