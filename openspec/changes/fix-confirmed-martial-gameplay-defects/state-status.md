## 额外发现与后续修正：如来掌无追加伤害分支

复核时如来掌始终预扣280，四掌结束未满足气门追加创伤时退80。这样能阻止追加伤害费用透支，但会改变**无追加创伤**的可支付加力：初始内力600、加力350，damage_bonus600、目标实际根骨至少100时，原固定200后余400，普通战斗严格`neili>jiali`允许一次加力，末值50；预扣280版余320，四掌不能付350，后退80末400。

这是明确的合法分支行为差异，不是负资源修复所必需的削弱。既有38/0版本只测实际根骨30的**有**追加伤害路径，不能反证上述差异。

主 Agent 确认后已按最小方案修改：先扣原固定200，执行原四掌，仍在原时点查询根骨；只有原气门判断成立且**当前余额>=80**时才付80并执行原追加创伤公式。余额不足时四掌保留、无免费追加创伤，也不返回0冒充整次未发动。取消无条件预留280及末尾退80，没有提前捕获根骨。

夹具已新增有/无追加条件、600/6000初始内力、加力0/350，以及真实普通攻击构造剩79/80（加力107扣三次/加力80扣四次）的临界用例。仅原COMBAT随机受控，不改费用计算、不在攻击中重设余额；原四次攻击、首击余额400、末值与是否返回追加创伤文本分别断言。新增用例已随w2EJNp的54/0与完整pF0WQ1的1994/0通过，不计入旧38/0。
