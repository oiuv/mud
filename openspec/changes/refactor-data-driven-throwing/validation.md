## 三轮性能测量

```sh
node tools/tests/test_cloth_objects.mjs bin/driver.exe --throwing --bench
```

原始结果：`mud-cloth-GLvWAW/benchmark.json`。每次独立启动驱动，按 27 个来源各创建 20 次，共 540 个实例；旧版 27 个蓝图，新版 26 个虚拟品种。顺序为旧/新、新/旧、旧/新。

| 轮次 | 旧冷加载 ms | 新冷加载 ms | 旧热创建 540 次 ms | 新热创建 540 次 ms |
| --- | ---: | ---: | ---: | ---: |
| 1 | 55.447 | 26.105 | 2.044 | 46.298 |
| 2 | 39.916 | 21.814 | 2.083 | 48.170 |
| 3 | 40.641 | 25.103 | 2.202 | 59.518 |
| 中位数 | **40.641** | **25.103** | **2.083** | **48.170** |

按热创建总时长中位数除以 540，单实例平均约 **0.00386→0.08920 ms**，增加约 **0.08534 ms**；这不是逐实例延迟的中位数。冷加载中位数减少 15.538 ms，不据此推算正式服总收益。

三轮内存估算一致：

| 项目 | 旧版 bytes | 新版 bytes |
| --- | ---: | ---: |
| 蓝图阶段 | 137,707 | 117,045 |
| 540 个实例增量 | 430,840 | 653,460 |
| 合计 | 568,547 | 770,505 |

合计增加 **201,958 bytes（约 0.193 MiB）**。加载阶段新增程序块 35→10，克隆阶段均未增加程序块。

这些是本机 `memory_info()` 估算，不是进程 RSS；“冷加载”指独立驱动的首次加载，没有清空 OS 文件缓存。测量期间另有消费者编译检查，数值只作为本次本机对照，不声称线上延迟保证或实例更省内存。
