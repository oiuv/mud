## 性能对照

同一机器、同一驱动、相同 6 个历史来源请求、120 个实例，旧/新各 3 个独立进程，顺序交替；测试期间不并行执行其他本次基准。全部六组原值见 [benchmark.json](benchmark.json)。耗时报告中位数，内存三轮相同。

| 指标 | 旧实现 | 新实现 |
| --- | ---: | ---: |
| 唯一蓝图数 | 6 | 4 |
| 冷加载合计 | 28.077 ms | 23.054 ms |
| 热创建 120 实例 | 1.509 ms | 11.511 ms |
| 平均每实例热创建 | 0.0126 ms | 0.0959 ms |
| 蓝图阶段驱动内存增量 | 53,549 B | 47,870 B |
| 实例阶段驱动内存增量 | 92,400 B | 133,400 B |
| 两阶段增量合计 | 145,949 B | 181,270 B |

热创建约为旧版 7.63 倍，绝对增量约 0.0834 ms/实例；本组总内存增量多 35,321 B（约 34.49 KiB）。这是虚拟创建和实例复合属性隔离的实测成本，不等同 OS RSS，不推断其他负载必然有相同比例。冷加载有波动（旧 25.612–59.450 ms，新 20.760–27.042 ms），不以小样本承诺性能提升。
