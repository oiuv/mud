# Proposal

## Why

武器分类规范化后，调用链审查发现双手占用可被操作顺序绕过、副手卸主手后失效、钝击招架回调混用伤害与结果码，以及两处武学资源/状态错误。先修复这些确定的机制缺陷，再讨论兵器特色和强度，避免在失效机制上做数值平衡。

## What Changes

- 统一主手、副手与手持物品的占用检查，装备顺序不再绕过双手要求；失败操作不改变原槽位、装备标记或属性。
- 按用户确认的规则，卸下主手后，合法副手自动转为主手，属性和实际武学同步生效；副手仍不提供额外攻击或属性叠加，不借修复新增双持战斗。
- 区分攻击结果与实际伤害，恢复默认钝击在真实招架时的既有兵器碰撞效果；闪避、零伤害和负伤害值不得冒充招架，不增加新触发概率或伤害倍率。
- 盘古七式「开天辟地」和撼山锤法「撼山震岳」的发动内力下限改为 500，与最大实际消耗一致；成功扣 500、失败扣 300、忙乱、教学与领悟条件保持。
- 修正罗汉棍阵的力量/身法属性键和双方阵法标记，保证增益真实生效、不能重复叠加、退出时只撤销本阵加成；保持原计算值、消耗和控制时长。
- 增加隔离真实驱动回归，同步开发说明和玩家更新日志。基本枪法、撼山锤法名称字典已在当前提交中存在，仅验证，不覆盖其本地运行期变动。

## Capabilities

### New Capabilities

- `weapon-combat-consistency`: 装备占用和主副手转换、攻击结果回调、指定绝招资源检查及棍阵临时效果的一致性。

### Modified Capabilities

无。现有主规范中的物品生命周期约束针对数据迁移；本变更不改物品身份、交易或持久记录结构。已完成但未归档的 `normalize-weapon-classification` 记录保留为历史基线，本变更显式说明其后续行为修正，不回写旧验收结论。

## Impact

- `feature/equip.c`、`cmds/std/hand.c` 及其 `wield`、`unwield`、移动/脱手调用链。
- `adm/daemons/combatd.c`、`adm/daemons/weapond.c`、必要的 `include/combat.h` 结果常量；统一更新已登记的攻击后回调。
- `kungfu/skill/pangu-qishi/kai.c`、`kungfu/skill/hanshan-chuifa/zhen.lpc`、`kungfu/skill/luohan-gun/shibaluohan.c`。
- `tools/tests/` 隔离测试、`docs/architecture/weapon-classification.md`、`help/changelog` 及相关玩家帮助。
- 不修改 mudcore、驱动、正式玩家/物品存档，不重启或部署正式服务。恢复碰撞与棍阵会改变实际战斗结果，不能将修复描述为无玩法影响或已完成平衡验收。

## Non-goals

本批不新增 EDGED/POINTED/LONG 被动，不改副手输出，不调整类别倍率、攻击节奏、武学获取门槛或物品定义。攻击者敏捷/根骨参与防守修正的疑点、历史 flags 值、小李飞刀死亡特例、定岳七方表现文案及类别平衡单列后续，不把尚未确认的设计意图作为本批自动改动。
