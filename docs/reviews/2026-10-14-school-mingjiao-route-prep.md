# 明教石门与密道采集条件

本批仅扩展离线采集工具，不修改游戏源码、正式配置或玩家数据。属于 `collect-martial-arts-dataset` 的有限门派依赖窗口，不代表完整明教、全部场景或全武学采集完成。

## 固定来源与执行范围

公开来源共 58 份，在既有秘籍的 50 份依赖基础上增加密洞、五处甬道及原 `open/go/close` 命令。顺序来源摘要为 `054a8cae911c691f7c7ab662a61cc3e2ea40d69ee2b382b2791801f99a94c3d7`。条件由 [路线模块](../../tools/tests/martial_data/school_mingjiao_route_cases.mjs)生成，游戏原文与各文件 hash 随系列冻结；沿用既有 15 个探针文件、48 个观察点，不修改原门逻辑或新增场景探针。

实验角色是隔离驱动内的普通连接 USER，不使用巫师豁免。属性、四项基本功和初始位置是明示实验准备，不等同自然养成；执行期间不补资源、不冻结时钟、不直接调用原开关门或磕头函数。观察器只查询已载入的房间、对象与计时器，避免观察行为改变房间首载顺序。资源保留原负值。

## 主组：8 条件，正式 16 条，烟雾 8 条

| 条件 | 初始内力／基本内功 | 原操作及观察 |
| --- | --- | --- |
| 错误参数 | 2400／300 | `break stone`，核对原拒绝，不进入扣费 |
| 内力不足 | 1999／300 | `break men`，命令受理与未开门分开 |
| 基本内功不足 | 2000／299 | `break men`，保留先扣 2000 的原顺序 |
| 内力 2000 | 2000／300 | `break men`，保留 -400，等待原回调关闭 |
| 内力 2399 | 2399／300 | `break men`，保留 -1，等待原回调关闭 |
| 内力 2400 | 2400／300 | `break men`，等待关闭，再原 `go enter` |
| 重复开门 | 4800／300 | 开门、等 2 秒、再开门、等 4 秒、等 2 秒；观察原计时替换，不手动回调 |
| 自然路线 | 5000／300 | 13 条原命令取得秘籍并行走，最后等待原关闭 |

原[石门逻辑](../../d/mingjiao/shandong.c#L27)检查当前内力 2000，随后扣 2000，再检查基本内功 300；开门后再扣 400，不把门槛改写成 2400。重复开门替换原 5 秒关闭计时。当前驱动 `call_out_info()` 的实现返回对象、函数、剩余时间三项，不包含回调参数；本批不虚构第四项或额外回调内部追踪。

自然路线为 `break men → go enter → go north → open north → go north → open north → go north → open north → go north → ketou → get qiankunbook → go south → go out`。前九条从密洞到密室；密室南出口按原源码回到 0 号甬道，0 号没有 `out`，最后一次退出尝试须记录实际拒绝，不能宣称已经离开。入口关闭与内部门的状态分别观察，不把 5 秒关闭解释成完整通关时限。

秘籍由原 `ketou` 产生并经原 `get` 取得，信为原克隆、书为原单例；同对象转移不计作再生成。测试结束销毁临时对象属于隔离清场，不是游戏中消费或重生机制。

## 独立首载组：3 条件，各 1 条

每条使用单独系列、单样本及独立驱动，不允许一起执行，也不以销毁重载代替独立首载证据。显式预载属于构造实验准备，不计入玩家命令或实际行走。

| 首载顺序 | 在 9 号甬道执行的原操作 |
| --- | --- |
| 9 → 密室 → 0 | `open north → go north` |
| 密室 → 9 → 0 | `close north → open north → go north → go south` |
| 0 → 密室 → 9 | `close north → open north → go north → go south` |

[9 号北出口](../../d/mingjiao/midao9.c#L13)通向密室，但[密室南出口](../../d/mingjiao/mishi.c#L18)通向 0 号。原公共门逻辑依据已载入对面房间复制／修改门状态，因此不得先假定出入口互逆或人为修正门状态。各加载步骤保存已载入对象、门、出口及库存，再记录命令的实际返回、收费、行走和终态。

## 证据与验收

`observed` 仅代表有限记录完整，不代表每次命令成功、场景设计正确或武功已学会。命令受理、内力收费、开关门、实际移动、自然回调关闭及书信交付分别统计。烟雾、正式组、首载组保持独立；保留失败记录与真实退出状态，不将纯工具自检当作真实玩法样本。

本文件记录执行前计划，实际运行结果另存报告；发现游戏逻辑或文案问题只登记，未获独立授权不修复。
