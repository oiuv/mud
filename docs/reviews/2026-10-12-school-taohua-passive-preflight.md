## 原源码口径

- [玉箫剑法](../../kungfu/skill/yuxiao-jian.c) 的 `hit_ob`（205–227 行）：输入伤害至少 120、已学玉箫剑法至少 160、`random(2)` 返回 0、当前内力至少 500、剑法映射为玉箫剑法，随后要求 `damage_bonus / 6 > victim->query_con()`。没有战斗、门派、有效剑法或“必须持箫”的附加门槛。
- 生效只扣施术者 60 内力，向目标 `receive_wound("jing", damage, me)` 请求 `damage_bonus * 2 / 3 + random(query_skill("chuixiao-jifa") / 2)`。LPC 整数除法逐步取整，吹箫使用**有效技能**。标准已学吹箫 200、有效 100，输入 600 的请求支持区间为 400–449；未学吹箫为固定 400；已学 400 时为 400–499。
- 函数读取主手的原名称来组装返回文本；原普通剑同样可用，不为夹具添加 `valid_as_xiao`。未配置主手不是本组合法实际调用链，不据人为缺武器调用提出游戏缺陷。
- [属性计算](../../feature/attribute.c) 的 `query_con` 使用原始根骨和**已学**基本内功：标准目标为 `36 + 600 / 10 = 96`，输入 581 的商为 96，不可生效；582 的商为 97，才可进入有作用的随机分支。输入 119/120 条件使用明确的根骨 9、基本内功 100，有效根骨 19，不用原始值替换真实 `query_con`。
- [原精神创伤](../../feature/damage.c) 的 `receive_wound`（54–85 行）将有效精神减去请求值，负数夹到 −1；当前精神只在高于新有效精神时下调。随后仅安排原心跳，不在当前同步栈直接执行昏迷或死亡。
- [真实资源观察器](../../tools/tests/weapon_balance/actor.lpc) 的 `set` 和 `observe_resource` 记录实际属性变动。[DBASE](../../mudcore/inherit/dbase.c) 的 `add` 经动态 `set`，所以扣除 60 内力可进入计数。计数不是 `receive_wound` 的请求参数；有效精神损失和当前精神损失不得相加为“总伤害”。
- 原 `receive_wound` 还会维护最后伤害来源，并在请求值大于 150 时调用 [USER](../../clone/user/user.c) 的 `improve_craze`。现有快照不直接观察这两项，本组明确记为 `not_observed`，不声称整个 USER 隐藏状态未变。
- [命令链](../../feature/command.c) 的 `force_me` 原样保留 `command()` 返回成本，不是 `hit_ob` 的返回值。正整数仅表示实验入口获受理；接口返回 0/null 仍为 `observed`，不当作命令拒绝、普通攻击落空或未执行回调。直接接口的返回字符串也不等于已经向玩家播放战斗消息。

## 观察及统计边界

每条要求一次原接口、一条 `route=interface` 的原被动事件，以及同源的调用前后双 USER 快照和返回。保持真实身份、技能/有效值、映射、准备、装备、耐久、学习进度及未变化资源。实际事件主体必须为左 USER 0、目标为右 USER 1；不接受 actor −1 或其他对象冒名。

空返回仅接受**键存在的** 0/null；必需数值、映射和计数缺失仍拒绝。忙乱/无条件的原空值与缺键分开。所有计数映射必须存在，稀疏未记录键才按原零计数解释；不能把显式 null 当零费用。精神创伤与 60 内力费用逐项闭合，任何额外损伤、费用/恢复相抵、攻击/直伤/心跳或装备磨损都不能通过。

两个夹制条件分别核验：

1. 精神 2000 小于伤后有效精神，精神成本应为 0，有效精神成本仍为实际 400–449。
2. 有效精神 200、精神 100 均夹到 −1，实际计数分别为 201、101；无论原请求是 400 还是 449，都不能由这两个差值恢复请求值。记录仍为即时存活 USER，没有被观察到的昏迷或死亡。

统计只消费冻结 `condition.parameters`，不需要 `raw.parameters`；任意结果在分类前先核外层/原件的条件 ID 和 outcome 同源。接口调用分母、满足确定门槛的调用分母、生效次数、空返回次数分开。守卫不满足不是施法拒绝，原接口生效概率也不是普通攻击命中率。

输出原请求量、暴怒值、最后伤害归属和后续昏迷/死亡均明确 `not_observed`。原请求仅附源码支持区间，不从损失猜测随机项；缺观察的样本进入未知分母，不变成 0 费用成功样本。两项精神损失各自统计，既不相加，也不冒充直接伤害请求。
