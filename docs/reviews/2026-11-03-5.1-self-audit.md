## 三、效果消费者原理

### 源码驱动验证

1. **效果契约匹配**：observed 必须有源码预期效果字段变化
2. **数值核对**：damage 需 ≥ min_value，拒绝副作用需精确值
3. **拒绝验证**：默认无副作用，仅源码在 notify_fail 前有副作用时配置
4. **注释剥离**：提取器先剥注释再提取，避免误判

### 与旧版区别

| 旧版 | 新版 |
| --- | --- |
| 任意变化算效果 | 源码预期字段才算效果 |
| 阈值 >1 判断伤害 | min_value 从源码提取 |
| 拒绝一律无气血变化 | 源码分支验证（qi_exact） |
| 正则可能匹配注释 | 先剥注释再提取 |
