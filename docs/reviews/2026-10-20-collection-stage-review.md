## 独立重验工具

`tools/review_martial_data.mjs` 读取传入系列的冻结条件、原始记录及 hash，用当前公共资源账检查和批次校验器重验。只支持 B1–B29 / slice1–8；其他组明确报不支持，不默认为通过。它不运行游戏、不读玩家存档、不调用模型、不修改原系列。

```powershell
node tools/review_martial_data.mjs --help
node tools/review_martial_data.mjs --out temp/replay-new.json <系列目录> [其他系列目录]
```

`--out` 只创建新文件，拒绝覆盖。缺记录、error、not_applicable、完整性错误和消费者失败均不算效果通过，退出码为 1；历史失败运行及工具快照缺口单独列示。该工具不提供跨系列去重总量，也不代替原驱动运行、全量覆盖审计或人工效果解读。
