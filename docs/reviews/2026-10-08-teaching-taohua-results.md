## 实际观察

- 按[十四项条件表](../architecture/martial-arts-schools.md#桃花岛普通绝招教学条件)检查成功、连续重复、非同门、贡献及原始技能不足；有有效内功、最大内力或额外知识／武学要求的入口，分别增加低一级／低一点的对照。不附加收徒条件，也不把叙述中的剑、箫或暗器变成玩家装备门槛。
- 天外清音与碧海潮生分别检查原始碧波神功，后者还检查碧海潮生曲；不能将其当成有效内功门槛。在碧海潮生的合法实验中，基本内功初始为 0，授课后因原奖励成为 1；这是询问授课结果，不表示实际学习或施展资格都已满足。
- 定昆仑的连续询问保留原忙乱：最终样本 `busy = 15`，贡献 `450 → 0 → 0`，弹指神通 `120 → 121 → 121`。第二问没有重置学生或忙乱，没有再次扣费／奖励。这里观察即时授课后的忙乱，不据此宣称已测量其自然结束时间。
- 破九域保留两次奖励：暗器及弹指神通各从 `180 → 182`，贡献 `1300 → 0`。转乾坤保留三次奖励：奇门五行 `200 → 203`、弹指神通 `220 → 223`、原未设置的基本指法 `0 → 3`，贡献 `2200 → 0`。采集不将多次奖励合并或修改数值。
- 天地情长授课叙述虽有“内力流逝”，原授课代码没有扣内力，实测当前内力保持 6000；不按文学叙述凭空增加资源支出。它的实际施展仍受已登记的 MA-001 错误技能 ID 影响，授课成功不抹去该问题。
- 各条件按原 `ask` 扣除精神；已有领悟的重复询问不再消耗贡献或增加熟练度。状态、扣费和私密消息分别核验，不靠命令返回 1 推断教学成功。
