# 独孤九剑：招架系数与受击化解

任务4.2的独立增量，**78条件／4174条记录**，均完成观察，0运行异常。包含54条系数查询、1720条化解接口观察、1200条原普通攻击、1200条公共直接伤害结算。返回0或未定义也是有效观察，不冒充化解成功；本批未修改游戏代码、公式或玩家数据。

## 条件与口径

- 左方是固定中性进攻者：基本剑、招架、轻功、内功各600，无特殊映射；有效剑法／招架300。`count`（公共字典名称“阴阳八卦”，不是算术）原始等级分别0、300。
- 右方是独孤防守者：基本剑、基本招架、独孤九剑同为200／400／800，剑和招架映射独孤；有效剑法／招架分别300／600／1200。基本轻功、内功固定600，无特殊轻功／内功映射。
- 双方均为真实连接的非巫师USER，四项先天属性30、经验1000万、气血及精神10000、内力及上限6000、加力0。测试剑伤害50、护甲100，不设置性格及互搏减忙。资格是实验赋值，不代表教师愿意传授或线上养成成本。
- `query_effect_parry`只查询系数；`valid_damage`传入1000伤害，只观察原返回及忙乱，**不自行扣血**。`ordinary`执行原`TYPE_REGULAR`，保留闪避、招架和反击；`direct`执行原`do_damage(..., WEAPON_ATTACK, 1000, 50, "")`，原装备加成后进入化解接口的伤害为1050。
- 41个随机条件各100次，37个确定性查询／门槛条件各两次。即时快照的忙乱整数不当作持续秒数；普通攻击系列不是30秒交锋，直接伤害系列不包含某项绝招的前置命中判断。

[原系数函数](../../kungfu/skill/dugu-jiujian.c#L539)已覆盖每个档位前后边界及800级，两次查询一致：

| 独孤原始等级 | 返回系数 |
| --- | ---: |
| 小于90 | 0 |
| 90～99 | 50 |
| 100～124 | 55 |
| 125～149 | 60 |
| 150～174 | 65 |
| 175～199 | 70 |
| 200～224 | 75 |
| 225～249 | 80 |
| 250～274 | 90 |
| 275～324 | 100 |
| 325～349 | 110 |
| 350及以上 | 120 |

[公共招架](../../adm/daemons/combatd.c#L601)执行`pp += pp / 100 * 系数`，再用攻击能力与修正后的招架能力判定；保留整数取整。120表示该项能力加成系数，不能解读为120%成功率。

200级持针、刀或空手都返回0；持箫返回75。原因是[针初始化](../../inherit/weapon/pin.c#L18)保留`skill_type=pin`，而[箫初始化](../../inherit/weapon/xsword.c#L21)设为`sword`。本轮按实际属性观察，不将名称相近当成同一条件，也不将这一差异自动列为BUG。

## 受击化解接口

[原函数](../../kungfu/skill/dugu-jiujian.c#L289)要求独孤至少120、持有实际剑类武器、清醒且不忙乱。普通有招使用攻击者有效招架加原始`count`对比防守者基本招架／独孤；无招改为防守者有效剑法对比攻击者有效招架，**不使用`count`**。

下表每格100次，数值为全额抵消传入伤害的次数，不是普通攻击招架次数：

| 防守等级 | 有招，count 0 | 有招，count 300 | 无招，count 0 | 无招，count 300 |
| --- | ---: | ---: | ---: | ---: |
| 200 | 44 | 0 | 75 | 77 |
| 400 | 100 | 50 | 100 | 100 |
| 800 | 100 | 100 | 100 | 100 |

对本配置，源码有招理论化解概率分别为50%／0%、100%／50%、100%／100%；无招为约74.67%、100%、100%，不随count变化。独立采样均值有波动，不能把75与77的差异归因于count。例：200级、count 0的有招44%样本区间为34.67%～53.77%，无招75%为65.70%～82.45%（Wilson 95%）；完整区间见JSON。

无招化解成功且攻击者原本不忙时，使其忙乱1或2；原本忙乱2的100次对照全部仍为2（其中71次化解），未叠加或刷新成其他值。接口不消耗双方内力。

边界观察：119级、忙乱2、空手、持刀、持针在有招／无招各两次均不化解。200级持箫有招51/100、无招70/100；零内力有招49/100、无招72/100。箫与零内力的随机波动不意味着另有加成或减益；相关原条件并不排除它们。

例如第一组100次中44次闪避、35次普通招架、21次进入伤害分支，其中10次随后被化解。原`RESULT_HIT`仍记录进入伤害分支的21次，**不能把该计数当成21次实际扣血**。800级两组没有进入化解接口，其“条件化解率”未知，而不是0%。多次调用可能受反击关联，不对调用次数直接套用独立二项区间；样本级事件另算。
