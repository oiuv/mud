# 陈家洛百花错拳入门采集结果

## 结果与范围

通过原 `learn chen jialuo baihua-cuoquan 1`、原 NPC 和真实非巫师玩家采集，新增 **21 条件、42 样本、44 次学习命令**。10 条样本发生子技能补授，32 条无进展；44 次交互中实际补授 10 次。所有结果符合已核对源码，没有替换传授函数或预写学习许可。

连同历史条件独立重跑，新完整系列为 **14 个目录分组、57 名教师、187 条教师／主题组合、1407 条件、2814 样本**；926 条有进展、1888 条无进展，共 3502 次交互（询问 3314、交书 90、学习 98），其中 20 次学习有等级或熟练度增长。旧系列不累加进新分母，拒绝对照不算采集失败。

## 原行为与门槛

来源是 [陈家洛 `try_to_learn_quan()`](../../kungfu/class/honghua/chen.c#L161)、[百花 `valid_learn()`](../../kungfu/skill/baihua-cuoquan.c#L209)、[原 learn](../../cmds/skill/learn.c) 与[师承判断](../../feature/apprentice.c)。教学先经过命令的师承检查，再由 `query("no_teach/...")` 执行原闭包；未直接调用回调。

| 对照 | 实际结果 |
| --- | --- |
| 正常入门 | 补齐十三路至 10 级，不创建百花错拳主技能，不写特别许可 |
| 同角色立即再学、十三路已全达 10 | 不再增长，不重置熟练度或扣费 |
| 查拳已有 20、八极拳只有 9 | 查拳保持 20，八极拳与其他不足项补至 10 |
| 已有百花错拳 100 | 不再补授；已有 151 而基本拳脚 150 时先被 `valid_learn()` 拒绝 |
| 神值 99999 | 闭包拒绝，命令返回 1，但没有学会任何技能 |
| 悟性 27、身法 22、最大内力 2999 | 分别拒绝；正常边界为先天 28／23、最大内力 3000 |
| 有效内功 249、基本拳脚 149、拳／爪／掌法各 99 | 分别拒绝；正常边界为 250、150、各 100 |
| 主手持剑 | 原空手检查拒绝，没有通过卸装或修改资格绕过 |
| 师父 ID 或姓名不符 | 无转世例外时原命令拒绝 |
| 转世门派为红花会 | 外层师承允许后，师父 ID 不符仍被回调拒绝；仅姓名不符、ID 相符则补授 |
| 当前精神、内力、潜能均为 0 | 最大内力等资格仍满足时补授成功，三项及学习点均保持 0 |

本组没有内功映射：基本内功 500 对应有效 250，499 对应有效 249。先天身法不是有效身法。十三路为查拳、八极拳、太祖长拳、六合拳法、燕青拳、少林长拳、八卦掌、八阵八卦掌、武当棉掌、虎爪手、鹰爪手、小擒拿手、大擒拿手；原 ID 与每次实际等级保存在样本中。

零消耗来自原回调在普通学习扣费之前返回 `-1`，不是测试免单，也没有清除学习时钟。当前武学修养为 0 仍能入门，不把后续合成的修养 80 门槛加到本处。转世字段是显式实验初值，只说明原分支，不代表完成转世或正常取得特殊许可。

## 边界与问题

- 本轮验证入门补级，不是十三路升至各 100 级后合成主技能；`get_finish()`、随机合成和后续施展尚未运行。
- 特别许可的实际取得、收徒、其他普通学习、兵器领取及完整门派能力仍待采集。持器对照只使用正常主手剑，没有伪造“只有副手”的状态，也不宣称枚举了所有持器状态。
- [MA-028](../architecture/martial-arts-data-findings.md#ma-028红花会人物与授课描写用字及动作错误) 补记授课“且记”应为“切记”；新增 [MA-029](../architecture/martial-arts-data-findings.md#ma-029百花错拳合成成功提示量词错误) 记录“演练了一片”应为“一遍”。后者只是静态文案确认，不冒充合成显示实测。
- 当前问题台账为 **29 组、全部未修复**。零费用、转世分支及正常强弱差异没有被自动判为 BUG。
