## 2. 两处针具领取

| 入口 | 库存与原资格 | 采集边界 |

| [李莫愁 `ask_zhen`](../../kungfu/class/gumu/li.c#L249)，`冰魄银针` | 师父姓名李莫愁；原代码却查不存在的武学键 `bingpo-zhen` ≥100；之后才查并扣同名库存字段，再创建 `/d/gumu/obj/bingpo-zhen` | 引用既有 [MA-023](../architecture/martial-arts-data-findings.md#ma-023李莫愁领取冰魄银针检查了物品式名称的技能键)。正确的冰魄神针 99／100／更高配充足库存，均保留真实技能门槛拒绝；错误师父另列。不注入错误技能键来制造成功，也不把未抵达的库存分支称为已验收 |

原 `create()` 都写库存 3，[小龙女 `reset`](../../kungfu/class/gumu/longnv.c#L231)和[李莫愁 `reset`](../../kungfu/class/gumu/li.c#L277)均将其重设为 `4 + random(2)`。必须记录实际构造返回后的库存、调用时间和原回调前后值。有限直接调用原 `reset()` 只能称为回调接口观察，不冒充经过自然刷新周期；若选择观察自然 reset，遵守所用驱动的[原调度](../../fluffos/docs/apply/object/reset.md)及实际配置，不改 `set_reset` 来声称正常刷新。不为凑出 4、5 两个结果重抽 RNG。

两个物品的原定义都是 **50 根／份**，并非询问文案所说的“一根”：见[玉蜂针](../../d/gumu/obj/yufeng-zhen.c#L29)、[冰魄银针](../../d/gumu/obj/bingpo-zhen.c#L29)。库存减少 1 份、物品新增数量 50 根分别记账；毒药与淬毒者两个身份按原字段记录，既有[身份待查说明](../architecture/martial-arts-data-findings.md#针具身份待查制毒者不等于淬毒者)不新增缺陷编号。

以下两项属于现有代码的实际行为，不能由返回值或成功文案替代观察：

- [原 `move(me, 1)`](../../feature/move.c#L104)遇容量不足时可改放到学生所在房间，仍完成移动；库存已预扣，发针函数不核最终持有者。区分询问受理、库存扣除、学生取得和落地；不把落地记作学生背包获得。
- [原合并移动](../../inherit/item/combined.c#L42)同步合并同路径物品，并销毁旧堆、由新堆保留累计数量。连续领取不能要求旧对象 ID 永存；记录各步前后对象、数量、真实持有者、房间堆、毒数据与负重。合并不是定时回调，不人为等待或重新补一份针。原毒战斗／零枚自然销毁已另有采集，不重复扩入本组。

## 3. 唯一银索与普通长鞭回退

入口为[小龙女 `accept_ask`](../../kungfu/class/gumu/longnv.c#L155)的“银索金铃”，原 [MASTER_D `give_item`](../../adm/daemons/masterd.c#L319)要求同门派、直接师父 **ID**、银索金铃技能 ≥150；没有该配置未声明的贡献费、正邪、性别或代数门槛。`give_item` 只在配置贡献 >0 时查贡献，不套用十三项 `teach_pfm` 的贡献逻辑。

[`/clone/lonely/yinsuo`](../../clone/lonely/yinsuo.c#L6)是实体单例：克隆会在原 `create()` 自毁，使用原 `find_object`／`load_object`，不得拿测试鞭或新克隆代替。[小龙女构造](../../kungfu/class/gumu/longnv.c#L97)只在单例无环境时取来装备；已经被占有则原样使用 `/clone/weapon/changbian`。

最小序列与独立条件：

1. 无占有的冷态创建第一位原小龙女，记录她实际取得／装备的对象；询问后再问，区分首次转移与已经在自己身上。技能 149／150、外派、同派非直接弟子用独立条件检查，不预写成功归属。
2. 单例已经由第一位教师／学生持有时创建第二位原小龙女，观察原长鞭回退，再经原询问记录占有拒绝。**在同一条件的两次构造之间不得销毁或强行取回银索**。
3. 代表性同门／外人／房间占有，至少一条容器间接持有，按原 `give_item` 向上追溯到角色或最外层环境；无环境与已经持有的状态分别保留。不因路径含 `lonely` 就假定所有环境都是教师。
4. 一条学生容量不足的原转移：可能先卸除教师的装备，再将银索落地。`give_item` 没有核验 `move` 返回或最终持有者；学生获得与教师失去／落地分别记。实际武器槽、`equipped`、装备 apply 和对象引用同步记录，不手工模拟卸装。

除明确初始占有安排外，后续只能由原构造／原询问移动；安排本身记录为实验准备，不能计作原 NPC 赠送。整个序列结束后才清理本条件创建的教师、受控持有者、物品和容器。独立冷态条件可以从已清理的隔离环境开始，但必须记录观察到的冷态，不把清理藏在询问步骤之间。

## 4. 四位教师的原拜师链

使用原 `apprentice <id> → attempt_apprentice → recruit <id> → recruit_apprentice`，不是直接调用 NPC 回调后推定拜师完成。林、李回调内使用 `this_player()`，原玩家命令上下文是必要条件。

| 教师 | [`gumu.h`](../../kungfu/class/gumu/gumu.h#L3)之外的原门槛 |
| --- | --- |
| [林朝英](../../kungfu/class/gumu/lin.c#L99) | 不是李莫愁弟子；**有效**悟性 ≥35；玉女心经基本等级查询 ≥120 |
| [小龙女](../../kungfu/class/gumu/longnv.c#L114) | **原始**容貌 ≥26，非 `query_per()`；不附加源码没有的女性门槛 |

| [李莫愁](../../kungfu/class/gumu/li.c#L113) | 性别不是男性；原始正邪值 ≤−70000；经验 ≥400000；有效内功 ≥160；基本掌法 ≥120。原条件不等同“只能女性”，无性应按原分支观察 |

公共门槛为 `detach/古墓派`、`betrayer/古墓派`、`betrayer/times` 均不能为真，已设门派不能是外派。每位教师保留一条合法基准、各自单项临界前后及共同拒绝，不与装备、性格、各等级作全排列。林／杨至少以一条“原始属性未达标、有效值达标”明确与启蒙条件不同；小龙女原始 25／26，不把临时容貌加成代入。

原 [apprentice](../../cmds/skill/apprentice.c#L7)还有独立行为，代表性覆盖即可：

- 忙乱直接拒绝；已有师父请安；同门同辈／长辈不能拜晚辈。这些可能先于 NPC 门槛，不能把它们统计为 `permit_recruit` 拒绝。
- 外派第一次只写 `pending/betrayer` 并提示确认，第二次才抵达 NPC 的同门检查；拒绝后可能保留 `pending/apprentice`。同一学生连续执行及取消，不预写两个 pending 对象来短接原流程。
- 原 [is_apprentice_of](../../feature/apprentice.c#L21)还读取转世门派；现有请安分支与新建师承分开，不假定所有条件都会进入 NPC 回调。
- 无门派首次成功时，原 [recruit](../../cmds/skill/recruit.c#L75)将贡献清零并删除持久／临时任务；同门转拜不套此清理。实际 `family` 全映射、`enter_time`、头衔、身份、贡献／任务、两个 pending 状态都要观察，不只核对 `master_id`。

所有师承、离派史、基本修为、先天属性等前提均为明示实验输入，不证明已完成正常养成；绝不在正式命令之间补资格或重新填满资源。

## 5. 最小共享接入与清理边界

现有机制可复用，但目前尚不能直接把这批条件挂上去并声称完整观察：

| 复用点 | 必要的局部补项 |
| --- | --- |
| [原教师准备](../../tools/tests/martial_data/runner.lpc#L1023) | 复用已连接普通玩家经 `test_interface` 创建原 NPC、保存确切对象、记录六动态武学加载位和构造前后状态。只标实际入口／返回身份，中途初始化主体仍可为 `not_observed`。不为未知技能角色强制 `enable` 或补技能；记录原心跳、原 NPC／蓝图／随身对象回调，再关闭克隆心跳，未知回调不得静默取消 |
| [原教学观察器](../../tools/tests/martial_data/teaching_observer.lpc#L133) | 口诀可使用 `monitored_grants` 观察原 wall 许可。黯然初授复用完整 skills／learned 快照，但须按原 `set_skill` 单独识别首次 0→10；[当前通用判定](../../tools/tests/martial_data/teaching_observation.mjs#L272)只把 `learn` 增长计为技能进展，不能伪造一个领悟键来绕过 |
| [拜师观察](../../tools/tests/martial_data/recruit_observation.mjs#L5) | 原 pending／师承／时间可复用。现有断言绑定旧组的“有效悟性等于原始悟性、有效内功等于基本内功一半”，古墓须按本组真实技能及映射核验；本组新增原始 per、有效 str、离派／叛师字段及任务清理观察，不放宽旧组契约 |
| 物品观察 | 现有 `teaching_item` 仅允许少林书信；不能拿蓝图 `find_object` 代替针具克隆，也不能借针法战斗组的 handing 替领取。增加仅本组开放的教师库存、学生／房间针堆、单例银索完整归属链、容量／负重、实际装备前后读取；观察器本身不创建、移动或加载物品 |
| 原始契约与报告 | 新增只读字段按本组限域，冻结原 NPC、物品、共享依赖和观察器。显式 `null`、数值 0、缺失分别按真实输出校验，缺少必需 mapping 不按零账放行；不依赖不存在的 `raw.parameters`。报告使用冻结 condition，并把命令受理、授予、重复、拒绝、落地及清理分母分开 |

针具合并后的旧引用可能已不存在，清理先核 `objectp`；受控 room／container 内的遗留针堆也属于本样本。银索的确切引用和前后环境跨全部步骤保留，已有 `clear_gumu_teacher()` 会清除教师库存，不能提前用于占有／回退序列。出错时仍回收本批创建的确切对象，不按名称查找并删除无关对象；不读写正式存档。

本轮仅新增本预检文档，未修改上述共享接入、游戏文件或已冻结数据；未将任何静态资格、合成样例或旧缺陷记录记为新实测结果。后续实现再锁定有限矩阵、通过真实 `createSeries/openSeries` 与入口校验、自检及独立烟雾，正式证据另建系列。
