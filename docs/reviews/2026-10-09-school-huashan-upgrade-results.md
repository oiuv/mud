# 独孤九剑：升级领悟与通晓奖励

任务4.2的独立增量：**31条件、1434样本、1846个连续步骤，0运行异常**。1434次“观察完成”不等于玩法无错误；本批确认重复奖励MA-066，只记录，不改游戏源码、数值或存档。

## 采集方式

两个真实连接的非巫师USER；学习者悟性39、根骨／身法36、性格狡黠多变、经验10亿，内力6000、精神10000。独孤与武学修养取配置等级，基本剑法为`max(200, 等级+2)`，剑／招架映射独孤，持测试剑。技能、领悟和资格均为实验初值，不代表师父当前愿意传授。

每步先经原`improve_skill("dugu-jiujian", 10000000, 1)`积累超过升级阈值的进度，保存预置前／后快照；再调用原`improve_skill(..., 0)`，或执行原`perform sword.jue`。前者仍增加1点进度，不是直接调用回调。原[公共升级逻辑](../../feature/skill.c#L300)自行提升一级、清空该技能进度并触发[原技能回调](../../kungfu/skill/dugu-jiujian.c#L571)。不改`learned[]`、不直接调用`skill_improved()`、不强制随机。

另用`weak_mode=1`作不升级对照。两步条件保留同一角色与全部状态，不重置领悟或修养；第二次积累同样显式记录。14个条件各100次、17个条件各两次。此方法验证调用与边界，**不用于估算正常练功速度、经验需求或养成成本**。

## 等级门槛与增量

原回调看升级后的原始等级：破气须大于120，总破须大于150。悟性39时，每个合格分支增加`random(13)`，即0～12；增加0也合法。无招许可直接跳过两项领悟，原值大于100亦跳过。

| 升级前→后 | 破气增量 | 总破增量 |
| --- | ---: | ---: |
| 119→120 | 0 | 0 |
| 120→121 | 6.51 | 0 |
| 149→150 | 6.31 | 0 |
| 150→151 | 6.33 | 5.62 |

各等级无招对照均升级一级，但两项领悟不变。普通API升级本身不扣精神、内力或潜能；总诀式300条另外各扣精神41、内力50～79，并增加基本剑法进度。原perform的额外弱模式进度可能保留于升级后，未误当第二次升级。

## MA-066：恰好100时重复奖励

[破气施展](../../kungfu/skill/dugu-jiujian/qi.c#L19)与[总破施展](../../kungfu/skill/dugu-jiujian/po.c#L20)均把领悟至少100视为已通晓；但升级回调使用`<=100`。领悟第一次刚好达到100并领奖后，下次升级仍会进入奖励分支，即使本次随机增量为0。

下表各100样本、每样本连续升级两次。另一项领悟固定101，隔离其奖励：

| 初始领悟 | 两步内奖励分支次数 | 从已100状态再次领奖次数 | 同样本领取两次 |
| --- | ---: | ---: | ---: |
| 破气99 | 110 | 10 | 10 |
| 总破99 | 102 | 3 | 3 |
| 破气100 | 109 | 109 | 9 |
| 总破100 | 108 | 108 | 8 |

最小连续证据：`school-huashan-upgrade-l200-qi99.0`的独孤200→201→202，领悟99→100→110，修养200→203→206；`...-po99.27`为99→100→106、修养同样200→203→206。这不是仅预写100后推测重复；已记录同一角色首次达到100、获得奖励、随后再次获得奖励。

每次分支调用三次`improve_skill("martial-cognize", 1500000)`；本表低等级条件每次实际升三级，但150万是函数入参，不等于固定经验、潜能或任何等级均升三级。原函数按当前等级取整，超过阈值只升一级并丢弃剩余进度。初始101及无招对照不领奖；弱模式四个样本八步骤均不升级、不领奖。

原总诀式路线另采初始领悟均100的120／150／200级各100次：实际升级121／151／201，分别进入一／二／二个奖励分支，修养增加3／6／6级。证明正常玩家命令也能触发该边界；仍不据预置进度推算刷取速度。此问题见[缺陷台账](../architecture/martial-arts-data-findings.md#ma-066独孤领悟恰好100时再次领取通晓奖励)，后续统一处理。
