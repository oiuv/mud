## 白骨爪：文字、附伤与整次攻击分开

[原 hit_ob](../../kungfu/skill/jiuyin-baiguzhao.c#L159)先要求传入伤害至少 100，再检查 `伤害 / 5 > 目标有效膂力`（整数除法）。成立时增加 `(伤害 - 100) / 2` 点气血伤势，并返回骨裂文字。

| 传入伤害／有效膂力 | 原文字触发 | 实际附加伤势（每条件两次） |
| --- | --- | ---: |
| 99／0 | 否 | 0 |
| 100／19 | 是 | 0 |
| 100／20、104／20 | 否 | 0 |
| 105／20 | 是 | 2 |
| 209／41 | 否 | 0 |
| 210／41 | 是 | 55 |
| 1000／36 | 是 | 450 |

因此，骨裂文字不能单独作为产生正附伤的计数依据。满气血角色的当前气血随伤势上限降低，不能把同一次上限钳制再算一份独立伤害。这个边界先记录为表现与数值口径，不擅自调整原门槛或新增伤害。

| 原普攻等级，每档 100 次 | 实际调用该被动 | 触发文字 | 整次普攻气血伤势下降均值 |
| --- | ---: | ---: | ---: |
| 200 | 54 | 2 | 37.90 |
| 400 | 75 | 31 | 76.15 |
| 800 | 96 | 91 | 190.28 |

最后一列包含原普攻本身，**不是白骨爪被动净增伤**。未走到被动的攻击不得当作被动已经调用但返回失败。随机、公共伤害、原动作缓存均不改；这三档不能推导实服胜率。

## 催心掌：施加与叠加

[原接口](../../kungfu/skill/cuixin-zhang.c#L139)要求特殊武学原始等级至少 80、加力至少 10、传入伤害非零；判定为 `2 × 加力 + random(等级) > 目标有效内功`。独立调用只挂异常，不即时扣气血、精神或内力。参数 factor 未被该函数读取，额外配置 10000 的 100 次仍遵循同一契约。

等级 79、加力 9、伤害 0 的各两次均不触发；等级 80、200、400、800、加力 10／100及伤害 1 的已配置合法条件均通过原施加流程。伤害 −1 的独立接口也被视为非零，100 次施加成功；这是显式接口输入，**不表示正常普攻会传负伤害**，不据此认定玩家可利用。

| 200 级、加力 10，目标有效内功 | 源码条件概率 | 实际触发／100 次 |
| --- | ---: | ---: |
| 19 | 100% | 100 |
| 20 | 99.5% | 100 |
| 119 | 50% | 50 |
| 218 | 0.5% | 0 |
| 219 | 0% | 0 |

有限样本未见低概率事件，不代表概率为零；校验器只对确定性边界强制结果，不将中间随机区间改成必须命中某个次数。

施加时强度为 `加力 + random(加力)`，持续输入为 `等级 / 100 + random(等级 / 10)`。[公共合并](../../inherit/condition/poison.c#L46)将其转换为“强度 × 持续输入”的剩余量，并非直接以秒倒计时。80 级的 100 次中有 14 次初始剩余量为 0；本批只观察这些样本的施加即刻，不冒称已测其完整后续。

400 条叠加样本分别预置强度 5／300、剩余量 600、同一／不同施加者。新剩余量追加，强度取较大者；同一施加者仍记原 ID，不同施加者记混合来源 `...`。每条都核对新强度与剩余量能对应同一组合法随机输入，不仅检查范围。

`special_skill/piyi` 经[affect_by](../../feature/condition.c#L223)阻止施加，100 次均无状态；`immune/poison = -1` 不在该入口拦截，100 次仍挂状态，免伤与解除发生在后续更新。两者不能混写成“完全一样的免疫”。

实际普攻三档各 100 次，催心被动分别调用并成功施加 58／76／96 次。这里只证明通过普攻可进入真实施加链，不将本次普攻伤害算成已经发生的毒伤。

## 原心跳后续

没有直接调用 update_condition、提前执行回调或缩短时钟。由[原角色心跳](../../inherit/char/char.c#L163)调度，原[异常宿主](../../feature/condition.c#L118)根据返回标志保留／清除状态，再决定是否自然恢复；观察探针只在原调用前后取快照。

| 条件（各两次） | 实际经过的更新 | 结果 |
| --- | --- | --- |
| 预置强度 200、剩余 200，有效内功 300 | 一次 | 先受毒伤，再解除 |
| 同强度、剩余 400，有效内功 300 | 两次 | 剩余 400 → 200 → 清除 |
| 同强度、剩余 400，无内功与抗性 | 两次 | 每次受伤，剩余仍 400 |
| 预置异常，诸邪辟易／完全免疫 | 一次 | 无毒伤，状态清除 |
| 原 hit_ob 施加，100 级、抗毒 200 | 一次 | 强度 13／10，分别扣气血 15／13、精神各 5，然后解除 |
| 原 hit_ob 施加，完全免疫 | 一次 | 先挂状态，后续无伤解除 |
| 原 hit_ob 施加，无内功与抗性 | 两次 | 持续受伤，剩余 289／130 均不递减 |

最后一项从原施加到第二次更新分别等待 23.164／19.145 秒；只是该观察窗口内仍保留，不以有限观察宣称永久持续。其余两次更新间隔和实际时间都在原记录中。完整记录共 22 次更新，其中 10 次继续、12 次清除；继续分支保持 `NO_HEAL_UP`，不将解除后的自然恢复混入毒伤数值。

[公共毒伤](../../inherit/condition/poison.c#L263)按强度分段并随机，强度 200 时气血损伤范围 41–123、精神 20–60，各伤势为该次损伤的一半向下取整。先损伤后检查恢复；恢复依赖有效内功／抗性判定，不是每次心跳必然扣一份剩余量。本批保留这一规则，不把“duration”变量名直接翻译成持续秒数。
