## 天罗地网掌：招架系数与额外化解

原[防御接口](../../kungfu/skill/tianluo-diwang.c#L97)分为两层：

- 招架激发须天罗原始等级大于30。额外招架系数在空手时为：不足60级取0，60–159取40，160–239取60，240–319取80，320及以上取100；主手持器取0。**系数100不是100%招架率。**
- 额外化解须天罗至少100级、防守者清醒且主手空闲。原判定为 `ap / 2 + random(ap) < dp`，其中 `ap = 进攻者有效内功 + count原始等级`，`dp = 防守者基本招架 / 2 + 天罗原始等级`；成功返回抵消本次传入伤害的结果。

以下为单独调用原额外化解接口，每格100次中的抵消次数；攻击者有效内功固定300，防守者基本招架与天罗同级：

| 天罗／基本招架等级 | count 0 | count 79 | count 80 | count 300 | count 1200 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 100 | 0 | 0 | 0 | 0 | 0 |
| 200 | 48 | 25 | 30 | 0 | 0 |
| 400 | 100 | 100 | 100 | 51 | 0 |
| 800 | 100 | 100 | 100 | 100 | 19 |

100级满足入口门槛，但此配置`dp=150`、`ap/2=150`，严格小于不成立；这不是技能失效。count从1级起就影响比较，80级只额外影响失败时的描述，不是化解抵抗的起始门槛。`mathematics`不等于`count`。

200级、count为0的独立接口对照：忙乱47／100、零内力52／100、攻击者持剑51／100、mathematics1200为51／100；防守者持剑为0／100。攻击者基本内功200（有效100）时100／100，基本内功2400（有效1200）时0／100。原接口不检查忙乱、内力或攻击者是否持器，检查的是防守者主手；原昏迷两次均未抵消。

**调用资格与已激发状态分开。** 取消映射后主动查询接口仍有50／100抵消，但普通战斗与公共直伤不会据此调用未激发的招架技能；不能把接口结果当成未激发也有被动效果。

正常200级普攻100次：51闪避、32招架、17命中判定；这17次才调用额外化解，其中7次抵消。400级为36闪避、54招架、10命中判定，随后10次全抵消。800级本条件没有通过闪避／招架的攻击，所以额外化解为**0次调用**，不是“调用后失败”。400级独立公共直伤100次则确实100次调用、100次抵消；这三种分母分别保留。

本批各条记录双方内力支出均为0。所有角色没有特殊内功映射，该结论只覆盖本批隔离配置，不意味着正常完整配功的战斗免费。
