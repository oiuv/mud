## 两层防御与调用路径

[原额外化解](../../kungfu/skill/shexing-lifan.c#L45)要求特殊等级至少100且角色清醒。令 `A = 攻击者有效轻功 + 攻击者原始count等级`，`D = 防御者原始基本轻功*2/5 + 原始蛇行等级`；按原整数运算，在 `A/2 + random(A) < D` 时返回抵消全部传入伤害的mapping。它不扣内力，不额外检查忙乱。

这是额外判定，不是普通闪避公式。[普通攻击链](../../adm/daemons/combatd.c#L703)在普通闪避／招架之后、原伤害仍为正时才调用已激活轻功的化解接口；[公共直伤](../../adm/daemons/combatd.c#L1020)只查询招架，不查询轻功。夹具新增的临时副本探针仅记录已返回的结果，不重复调用或抽随机；移除探针可逐字还原。

### 独立接口

以下每格为“成功次数／100”，不是对全部攻击的免伤概率。攻击者有效轻功300，防御者基本／特殊轻功同级。

| 防御等级 | count 0 | count 99 | count 100 | count 400 | count 1200 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 100 | 0 | 0 | 0 | 0 | 0 |
| 200 | 44 | 19 | 22 | 0 | 0 |
| 400 | 100 | 92 | 92 | 36 | 0 |
| 800 | 100 | 100 | 100 | 100 | 28 |

例：200级、count0的源码条件概率43.33%，本次44%，Wilson 95%区间34.67%—53.77%；400级、count400的源码概率30%，本次36%，区间27.27%—45.76%；800级、count1200为24.67%，本次28%，区间20.14%—37.49%。这是本配置分布，不据此给门派排名。

99级五个count组共10次、原昏迷400级两次均返回空值。100级虽然已过资格门槛，但本批基本轻功同为100、`D=140`，仍小于`A/2`，所以没有成功；不能误写成技能要200级才启用。400级忙乱、零内力、攻击者持剑三组均100/100化解；这些对照的判定参数仍保证成功，不证明任意对手都无法命中。

将攻击者`mathematics`设为1200而count保持0，200级接口41/100化解，源码概率仍43.33%。实际读取的是`count`，不是算术`mathematics`；随机差异不等于后者参与公式。

## 练习与文本

[原练习接口](../../kungfu/skill/shexing-lifan.c#L33)要求气血至少150、当前内力至少200，每次扣80气血、120内力。149／150、199／200边界分别以接口和原命令核对。[公共命令](../../cmds/skill/practice.c#L62)另要求基本功高于特殊功，并检查经验、战斗、忙乱、映射和次数；直接接口成功不等于命令一定允许。

基本轻功为特殊等级加一、悟性36时，200／400／800级单次进度分别12／7／3点；299→300级为13→7，499→500级为7→3，来自原分段与[进度折算](../../feature/skill.c#L295)，不是本轮调整。每种确定性结果重复两次。

200级一次要求50趟，实际扣4000气血／6000内力，增加600熟练度。气血230或内力320时要求3趟，只完成2趟，扣160／240、进度24；命令返回0但有真实进度，不记为完全拒绝。持剑仍可练轻功；忙乱、战斗、未激活、基本功同级、经验799999、次数0／51均拒绝且无进度。练习接口本身只扣费，不自行增加熟练度。

`valid_enable`允许dodge／move，拒绝parry；`valid_learn`四条件8次均允许，包括零资源输入。不存在独立`query_effect_dodge`，调用空值不记为一个“加成0”的实现。

为[MA-109](../architecture/martial-arts-data-findings.md#ma-109峨嵋对话与招式描述文字问题)第19／20处补实证：[第7行](../../kungfu/skill/shexing-lifan.c#L7)“身行”在100次原闪避文本查询中返回16次，普通攻击147条样本实际显示该字；[第19行](../../kungfu/skill/shexing-lifan.c#L19)动作查询两次均返回“身行”。后者仅证明接口原文，不冒充正常战斗选择此动作。**两处均未修复**，该组21处现为12处实证／9处静态；全台账仍111组。
