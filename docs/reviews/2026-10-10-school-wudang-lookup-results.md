# 公共寻人入口：特殊许可、查找路径与位置报告

本批只采集，不修改游戏源码、门派配置、正式数据或服务。三门武当内功分别通过原 `exert` 回退公共 `force/xun`，不是三套独立寻人算法，也不证明普通玩家可取得该特殊许可。

## 范围与结论

42个条件、84条正式记录：48条进入观察、36条按原条件拒绝，0运行错误、0校验错误、0残缺记录。48条观察中，36条正确报告本批目标位置，**12条复现MA-081：实际移动后仍报告旧位置**。因此“数据采集通过”不等于“寻人功能全部正确”。

每门内功有14个确定性条件，各重复2次；不把这些条件按随机伤害样本采100次，也不混算独立烟雾84条。角色均为隔离真实USER，调用者有连接且非巫师；`can_perform/wiz_test`、`quest/id`是明确的实验赋值。

| 条件（每项三门内功合计6条） | 实测结果 |
| --- | --- |
| 玩家ID／生物ID／对象路径 | 分别经原find_player／find_living／find_object找到目标；生物ID使用从未连接的临时USER，不冒称玩家查找 |
| 无place／普通place | 目标不移动，输出实际所在的演武场 |
| place为“西域”／“很远的地方” | 目标从演武场移至原佛山大镇街，输出仍是演武场；两项合计12条均复现 |
| 无许可／无quest/id | 原提示“没有这种功能”，不发动、不移动 |
| 查无目标／目标没有环境 | 分别提示未找到人物／不知道所在位置，不发动 |
| 忙乱／未激发内功 | 原命令层提前拒绝，原原因单独保存，不当作xun入口已经执行 |
| 命令显式指定left，但quest指向right | 实际仍报告right：xun内部重新按quest/id查找，不使用已解析的显式目标 |
| 内力为0 | 在本批其他资格满足时仍能定位，不扣内力；不据此推定其他公共内功免费 |

所有样本中双方已观察的气血、有效气血、精神、有效精神、内力及忙乱未因该命令改变。成功样本的基本内功学习进度增加1，来自[原exert成功后的improve_skill](../../cmds/skill/exert.c#L29)，不是xun额外收费或强化。当前基本内功200，原随机判断必成立；不外推低等级进度概率。

## MA-081的实际证据

[原xun](../../kungfu/skill/force/xun.c#L23)先保存 `where`，第31行移动目标，第33行仍输出保存的环境。本批原输出为：

```text
右试弟子(right)现在在演武场(/tests/runner).
```

同条记录的实际目标环境已是 `/d/foshan/street3`。原命令返回成功，公共入口发动记录为1，但位置不正确。源码SHA-256为 `6faa9f9e388a7111eb107817b89bb9ed97c6ee2b17f28944c977aacb0c7b85f5`，问题只登记到[MA-081](../architecture/martial-arts-data-findings.md#ma-081公共寻人移动目标后仍输出移动前的位置)，未修复。
