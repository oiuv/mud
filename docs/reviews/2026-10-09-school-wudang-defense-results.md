## 两种太极的化解判定

[太极拳](../../kungfu/skill/taiji-quan.c#L318)与[太极剑](../../kungfu/skill/taiji-jian.c#L318)都使用：

```text
ap = 攻击者有效内功 + 攻击者原始count
dp = 防守者原始基本招架 / 2 + 防守者原始太极等级
ap / 2 + random(ap) < dp 时，返回 damage = -传入伤害
```

资格要求特殊武学至少100级、防守者living。太极拳要求无主手武器；太极剑要求主手实际为sword。两者都没有忙乱、当前内力或攻击者持器禁用条件，不能套用独孤或空明的检查。副手及非living状态本批未独立构造。

三种进攻者配置：未激发特殊内功时有效内功300；另加count 300后ap为600；仅激发600级玄门内功后有效内功900，count仍为0。`count`不是`mathematics`。下表每格为**接口化解次数／公共直伤化解次数**，每个分母分别100；不是每100次普攻的化解率。

| 太极／进攻者配置 | 200级 | 400级 | 800级 |
| --- | ---: | ---: | ---: |
| 拳：有效内功300、count 0 | 54／50 | 100／100 | 100／100 |
| 拳：有效内功300、count 300 | 0／0 | 43／48 | 100／100 |
| 拳：有效内功900、count 0 | 0／0 | 11／12 | 85／75 |
| 剑：有效内功300、count 0 | 51／53 | 100／100 | 100／100 |
| 剑：有效内功300、count 300 | 0／0 | 43／48 | 100／100 |
| 剑：有效内功900、count 0 | 0／0 | 12／20 | 81／81 |

对应原整数公式的理论比例，三种配置分别是50%／100%／100%、0%／50%／100%、0%／约16.67%／约83.33%。原判定相同，不把两种太极的有限随机样本差值解释为公式不同，更不据此排名门派。完整分布及样本级Wilson 95%区间保存在JSON；工具只验证数学上必定成功／失败的边界，不强求随机频率等于理论值。

公共直伤实际落实原返回：200级、有效内功300且count 0，太极拳／剑的目标气血支出均值为621.25／592.70；800级、有效内功900时为311.25／231.65。这些均值含未化解样本，创伤另存、不相加。全部直伤样本中成功化解后气血／有效气血支出均为0，失败者实际扣血；本隔离配置没有其他防御替代因素。单独查询全部保持角色快照不变，不能拿其零伤害与直伤作输出比较。

## 普攻中的两层防御

普通攻击先经历闪避和常规招架，再可能调用化解接口。200级、有效内功300且count 0的100次普攻：太极拳调用化解15次、成功9次，太极剑18次、成功6次；其余攻击并非化解接口“失败”。400级同配置分别调用5／3次且全部化解，800级分别1／0次。800级两种太极面对有效内功900的普攻均未调用化解，不能因此写成化解率0%。

同一攻击即使返回公共`RESULT_HIT`，后续也可能已被全额化解。上述200级太极拳的15个命中标签中含9次化解，目标气血支出均值仅7.61；标签、接口返回和实际损失分别留证。没有将一条发起动作先验当作一次命中；原反击保持开启。

两者[招架系数](../../kungfu/skill/taiji-quan.c#L397)的等级档位相同；[剑的持器限制](../../kungfu/skill/taiji-jian.c#L400)独立保留：

每格每种技能各2次。公共战斗[使用方式](../../adm/daemons/combatd.c#L593)是`pp += pp / 100 * 系数`，保留整数截断；系数120不是120%成功率。忙乱会先把常规招架计算值除以3，但不等于后续太极化解函数禁用。本批忙乱对照只独立验证化解／直伤，不据此宣称完整忙乱普攻收益已测。
