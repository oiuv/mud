成长观察中，试验方基本兵器、特殊武学和武学修养采用 200/400/800 档，基本内功、轻功与招架仍各 600；目标保持原配置。这不是角色所有技能同时升级。例如“群邪辟易”的基本轻功加成没有随特殊剑法档位一起增长，不能据此拟合完整门派的成长曲线。

“缠字诀”和“金蛇吐雾”的成功条件都是 `level / 2 + random(level) > 对手基本轻功`。对本轮原始轻功 600 的目标，200/400 档的最大左值分别为 299/599，因此这两个档位发动后必不进入成功分支；800 档则可能进入。这个结论来自明确条件，不是用少量未命中样本估计零概率。独立弱目标机制用例用于观察成功控制/致盲，不能与标准目标均值混算，也不能把标准档失败判作招式无效。

同样，施展末尾的忙乱快照只是剩余状态，连招中间控制可能被命中打断；具体口径见[采集方法](martial-arts-dataset.md)。各招的内力、弹药、控制和目标资源须分别呈现，不按一张气血表作统一强弱排名。
