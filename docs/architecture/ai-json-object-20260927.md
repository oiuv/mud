# 简化架构与原生 JSON Object 实施记录

## 实施范围

本轮落实 `evolve-ai-capability-runtime` 的简化设计，不新增执行框架、计划工具、Schema 转换器或格式修复模型。

- 通用 Agent 默认文本；NPC、主 Agent 业务结果及世界正文通过 `json_output=True` 显式使用 JSON Object。原来的工具循环、思考续行、证据核验与业务提交保持不变。
- JSON 请求不发送 `max_tokens`，以 `OPENAI_MODEL_MAX_OUTPUT_TOKENS` 预留最大输出，格式开销计入上下文。摘要和 compact 保持文本及自己的输出上限。
- 主 Agent 负责通用目标，按需调用专业 Agent；Skill 只提供必要指导，明确场景才指定工作流。主协调、NPC、源码 Skill 分别更新至 v4、v5、v13，取消统一固定步骤和清单要求。
- 工具参数错误返回原授权参数定义，帮助模型自纠；不替模型改参数，不泄露私密参数值，不扩权。
- 合成业务探针显式关闭源码能力，防止默认仓库读取把合成联调变成真实源码调查；正式服务的默认源码设置不变。

## 发现与修复

首次全量回归发现旧测试仍要求 NPC 发送 `max_tokens`，以及小窗口 compact 夹具未声明相应最大输出容量；已按新契约修正并重跑通过。

首次非思考源码批次发生重复参数错误：Flash 给 `source.search` 传入未声明的 `path`，收到笼统错误仍重复。该批次已协作取消并保留结果；随后为所有工具补充通用参数反馈，未为该题或搜索工具新增特例。另一个旧合成业务探针意外暴露仓库读取能力，已停止该测试进程、修正隔离并以独立新批次通过；原中止批次的在途消耗不能视为已完整结算。
