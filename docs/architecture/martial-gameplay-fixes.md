# 武学效果与教学维护

## 教学与资格

询问传招写入实际绝招读取的许可，奖励对应武学。重复询问不重复领奖或扣除该次传授费用；补授低阶武学只补不足部分，不降低已有等级。物品交付成功后才结算贡献。

拜师、询问剃度和跪拜确认分别遵守对应门规。已取得剃度邀请并不免除确认时的资格复查；一次确认消费一次邀请。

## 属性、资源与选招

- 武学共享蓝图中的动态招式按当前出招者计算，返回的动作数据不被下一名角色的调用改写。
- 招式候选遵守原动作的等级比较；名称查询使用同一动作的名称字段，不改原门槛或数值。
- 费用检查与实际消耗的气血、精神、内力或弹药一致；完整必要费用先于可能继续耗能的公共攻击结算，不通过事后归零隐藏透支。
- 如来掌保留原固定费用与四掌，在原判断时点且余力足够时才支付并施加额外创伤；不提前占用未知分支的费用。
- 归元的根层临时 `dex` 供公共防御计算，`apply/dex` 供有效身法计算。施加和结束分别维护两处本次增量，不能只迁移其中一处而丢失原贡献。临时 `str` 仍有公共战斗消费者，不可当作无效旧字段机械替换。

## 武学与场景约束

- 裘千尺传授的铁掌无影掌为 `perform strike.ying`。激发并准备铁掌掌法、空手交锋，铁掌100、有效内功160和120内力才可施展。对手可凭轻功避开；命中只结算一次普通掌击，不叠加控制。龙影掌原效果不变。
- 靛沧海的基本内功须先达到200级，并领先当前靛沧海至少10级；原拳脚、根骨、内力、空手和独立/合修互斥要求不变。神照经仅作内功，运劲与护体保留，不开放旧徒手招式。
- 西域铁筝音与铁琴音一样略过护命保护对象，不引起伤害或交战。明教密道9号的北石门只控制进入密室；密室南侧仍通0号，不向其他石门同步状态。
- NPC 的自动招式须与实学、激发、准备和持器匹配。没有对应条件的槽位应删除；同一轮删除多个槽位时，检查其余招式是否被动增频。林朝英保留原剑，使用已有玉女素心剑。

## 生命周期

强化结束按施加时记录的增量撤回，不按结束时的新技能等级重算。反两仪刀阵保存成员及各自增量，成功移动、有效队伍变化和正常宿主 `destruct()` 撤阵；宿主先执行原移除流程，未被拒绝才撤阵。重复解除不得再次扣数值，独立队伍不受影响。

显式 `efun::destruct()` 会绕过宿主销毁包装，不属于该包装的保证范围。共享 `no_quit` 的相同布尔值没有来源信息，不能据此判断任意其他效果的所有权；现有解除保留可识别的后续不同值。

乾坤反击在排队时保存攻击者标识；回调在反击、离战或攻击者消失后清除自己的待执行标记，保留其他独立标记。

房间生成 NPC 的默认据点、召援和回程见 [NPC归属](npc-room-ownership.md)。

## 验证与部署

定向修复测试：`node tools/tests/test_martial_audit.mjs`。可用 `--group=fields`、`--group=npc_fixes`、`--group=state_cost`、`--group=combat_cost`、`--group=room_home`、`--group=design_fixes` 或 `--group=closeout` 分组；`array_form`、`array_exit`、`array_remove`、`last_ammo` 可分别隔离阵法入口、撤阵、对象移除和末枚暗器。路径可作为首个位置参数指定驱动。相应 `--before=<组>` 只读取固定旧提交到隔离副本，不回退工作树。

文案边界检查：`node tools/tests/test_martial_text_fixes.mjs`。纯文案文件须与声明替换后的原 token 序列完全一致；混合文件的功能改动另由功能断言验证。

统一核心回归：`node tools/test_gameplay.mjs`。上述运行不连接正式服、不调用模型、不读写真实玩家存档；通过不代表全库无缺陷或正式服已加载。

更新应安排在正常维护窗口，建议重启以清除旧蓝图与活动效果。历史错许可、旧奖励和已存在的状态不自动补偿或迁移；旧阵法没有新快照时不承诺直接热更可恢复。玩家更新说明在 `help/changelog`。
