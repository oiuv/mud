# 房间生成 NPC 的归属

宿主房间 `/inherit/room/room` 的 `make_inventory()` 复用 CORE_ROOM 的创建、`home` 设置和移动流程。返回的角色若没有有效的非空字符串 `startroom`，补为生成房间的 `base_name()`；NPC 构造时已明确设置的 `startroom` 保持不变。普通物品不新增这个角色字段。

`home` 继续保留框架原有含义；`startroom` 供宿主守卫判断是否位于自己的据点，以及援助者结束支援后归位。守卫离开自己的据点时不会因此获得异地召援能力。房间重置复用已有 NPC 时，不重新覆盖其归属。

这一默认值只在房间新建 NPC 时补齐，不修改玩家存档，也不修改 mudcore。直接克隆或其他业务生成 NPC 的流程不受此入口影响，仍由对应业务设置必要归属。

## 更新与回滚

只热更新房间继承文件不会给已加载的旧 NPC 补字段。部署后应重启游戏，或按维护流程重新生成相关 NPC；不要将仍被引用的旧 NPC 直接改作新对象。回滚恢复原代码即可，本次没有存档迁移。
