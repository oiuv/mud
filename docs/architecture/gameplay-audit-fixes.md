## 交易与背包

| 问题 | 修复契约 | 主要源码 |
| --- | --- | --- |
| 负数/零数量、异常售价、乘法溢出导致错误扣款或找零 | 交易输入完整解析为有界正整数；付款入口拒绝非正值；金额乘加前检查范围 | `feature/dealer.c`、`adm/daemons/moneyd.c`、`adm/daemons/shopd.c`、`cmds/usr/buy.c`、`clone/misc/shang-ling.c` |
| 默认 50 颗的堆叠物品只记一颗库存却交付整组 | 店铺、摆摊按库存基本单位创建交付数量，保持物品总量守恒 | `shopd.c`、`buy.c`、`dealer.c` |
| 部分存入先拆分，禁存失败丢失数量 | 验证原对象再记录、扣量，不克隆候选绕过原实例禁存属性；拒绝返回失败 | `feature/user_storage.c` |
| 背包取出失败已扣记录 | 成功交付才扣相应数量；未取出的记录保留，失败候选清理 | `feature/user_storage.c` |
| 只识别 `.c`，新秘籍静默拒收 | 使用现有 `lpc_file()` 支持实体双扩展名，保留已有虚拟品种准入 | `feature/user_storage.c` |

不改变背包持久格式，不放开饮食、临时状态、唯一物品或其他禁存规则。
本轮不转换既有异常存档、不引入通用交易框架。

## 武学与恢复

| 修复点 | 结果及保留边界 |
| --- | --- |
| 九阴摄心共享恢复定时器 | 每个目标独立到期；重复施展的旧回调不能清除新效果 |
| 抽髓掌碧焰反噬共享定时器 | 不取消其他施术者的反噬回调 |
| 冰心诀错取自身防御、给对手增加内力 | 防御取目标功力；中招消耗目标内力，最低归零 |
| 参合绝招等级赋值被比较表达式覆盖 | `clv` 保存实际修为，参与原反制等级差判断 |
| 参合命中特效选择其他敌人、赋值优先级错误 | 使用实际 `victim` 的六脉等级和准备状态 |
| 太玄实际分发文件技能名和准备参数错误 | 读取真实太玄等级；空手须正确准备，旧同名文件一并修正 |
| 碧焰读取 `force, 1` 错误技能名 | 读取基本内功等级，保留其他命中项 |
| 如影增益写入无效属性 | 使用公共 `apply/str`、`apply/dex`，结束撤回本次加成 |
| 两种轻功练习误扣 `neill` | 神行百变扣内力 14，倒转七星步扣 24；门槛不变 |
| 神行缥缈、碧云提升可透支 | 当前内力至少 100，成本仍为 100 |
| 袈裟附加击倒可透支 | 基础 300 与附加 500 一并可支付（800）才触发附加效果 |
| 参合命中特效可透支 | 当前内力至少 80 才扣 80 并触发，其他门槛不变 |
| 醉酒、先天“五气朝元”、血刀“浴血重生”调用不存在的恢复接口 | 使用 `receive_heal()` 恢复当前气血/精神；有效上限仍由原接口控制 |
| 疗伤自然结束清错状态 | 清 `pending/healing`，不误清其他运功状态 |

不钳零掩盖内力不足，不迁移历史 `neill` 字段，不改变未列出的技能数值。
