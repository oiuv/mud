# 武器分类规范

双手占用、主副手切换、攻击后回调及指定武学修复见 [武器战斗契约](weapon-combat.md)。

## 分类依据

按实际形制、主要用法及所属武学判断，不能只看文件名或历史继承。

| 类别 | 继承与初始化 | 主要用途 |
| --- | --- | --- |
| 枪 `spear` | `SPEAR` / `F_SPEAR`、`init_spear()` | 枪、叉、戟等长兵器，以刺击为主；基础标志为 `LONG | POINTED` |
| 斧 `axe` | `AXE` / `F_AXE`、`init_axe()` | 有刃斧器，劈砍类伤害 |
| 锤 `hammer` | `HAMMER` / `F_HAMMER`、`init_hammer()` | 实际锤器及明确的钝击武器 |
| 棍 `club` | `CLUB` / `F_CLUB`、`init_club()` | 棍棒及杆秤等棍系持器 |
| 杖 `staff` | `STAFF` / `F_STAFF`、`init_staff()` | 杖类及所属杖法体系 |

枪类替代旧 FORK，不保留宏或路径别名。棍与杖保持独立，不因底层动作相近而合并，也不预设新的强弱差异。火器不是长枪，流星锤等软兵器不因名称含“锤”就归普通锤；其他现有类别不随本次调整。

## 同步要求

- 普通品种的数据及 `/d/items/<类别>/<ID>` 路径一起归正，更新创建、比较、交易、刷新和存取白名单；专用对象保留独立生命周期。
- 基本技能、特殊武学、NPC 持器、激发、教学、练习和绝招应成套匹配。没有特殊武学的兵丁不凭改类获得新武学。
- 明确错类可以修正直接关联的行为；无关伤害数值、门派资格、消耗及特殊效果不顺带重做。
- 同名品种经用途核对可消除无必要的细微差异。记录原值、目标值及理由，不拼接各版本的最高属性；任务身份、限制和必要档次继续区分。
- 不改写历史测试快照，以明确差异清单核验新结果；没有测试的项目不能标为完成。

本轮六项移类、十九项品种归并及全部同名候选的保留理由见
[武器归并核对清单](weapon-normalization-review.md)。当前定义按现有代表版本统一，
并不保证旧版本的估价及所有细微数值仍相同。

## 玩家数据与部署

`query_skill_map()` 保留原始记录；`query_skill_mapped()` 只返回通过当前
`valid_enable(类别, 使用者)` 检查的激发，实际有效等级、动作选择与绝招共用该结果。
不在读取时删改映射。依赖等级、转世或领悟条件的 `valid_enable` 必须使用传入的角色，
省略第二参数时才回退到 `this_player()`，避免 NPC 战斗和后台查询误用其他玩家的资格。
`skills` 的激发标记和 `enable` 的当前列表也读取有效映射，不能把仍保留在原始记录中的错类激发显示为正在生效。
基本斧法与其他基本兵器武学一样归属 `martial`，遵守武学经验门槛与研究规则。

基本枪法的公共学习入口为扬州陈有德：保留原新手缴费教学，经验达到 3500 的
老玩家可缴纳 500 铜钱获得仅限 `spear` 的临时补学资格，按正常 `learn` 教至 80 级。
不将补学资格写入原新手通用缴费标记，不改原已获资格的行为；潜能、精神和经验等
学习限制仍由既有命令处理，基本枪法已达到教师等级时不再收取补学费用。
`clone/book/basic-spear.lpc` 复用 BOOK 与 `study`，使用其他入门秘籍的参数，
陈有德初始备货五本，仍按现货规则计价。该书 `max_skill=19`，沿用 `study` 的
现有等级判断；不把此参数另行实现为新的研读逻辑，不授予特殊武学或绝招。

赵鹤传授撼山锤法，询问“撼山震岳”使用已确认的门派、师承、膂力、贡献、邪气、
内功与特殊武学门槛；新领悟使用 `can_perform/hanshan-chuifa/zhen`，不复制旧领悟。

本轮不读取、转换或写入正式存档，不自动复制、删除、补偿基本功、特殊武学、熟练度、激发或绝招领悟。玩家主动学习并重新激发；使用时应按当前类别校验，不依靠旧错误映射取得错类效果。

删除旧物品路径可能使旧仓库、商店或 NPC 装备引用无法恢复。代码回归通过不等于旧记录无损升级；存量处置和正式重启另行决定，不增加运行期兼容壳。不要仅热更新一个数据表就宣称部署完成。
