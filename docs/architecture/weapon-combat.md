# 武器装备与战斗契约

本文说明装备占用、战斗回调与结算规则。类别、教学和路径规范见 [武器分类](weapon-classification.md)。

## 双手占用与装备切换

- `TWO_HANDED` 独占双手，装备顺序不能绕过限制。
- 单手主武器最多与一件 `SECONDARY` 副武器或一件 `handing` 物品共存。
- `wield()`、`hand` 先检查各自原有的资格、耐久或重量要求及双手占用，再改变状态；失败保留原持物及属性。手持转装备只在成功时释放原手持位置。
- 只有主手贡献 `weapon_prop`。副手不是双持额外攻击，也不叠加伤害或其他武器属性。
- 主手经 `unequip()`、正常 `move()`、销毁或脱手离开时，合法副手自动转主手，扣旧加成、加新加成并更新动作。转持复查归属、可用性和占用；不合法者解除装备，不销毁或丢弃。
- 主手降为副手属于内部换位，不递归调用卸装。正常物品生命周期仍负责卸装。

## 攻击后回调

```lpc
void post_action(object me, object victim, object weapon, int damage, int result);
```

第四项保留战斗结算传出的伤害值（包括零或防御钩子产生的负值）；第五项独立取
`RESULT_HIT`、`RESULT_DODGE`、`RESULT_PARRY`。不得用伤害推测是否招架。
新增回调须遵守这一顺序，并核对参与对象是否仍有效。

默认动作 `bash/crush/slam` 的 `bash_weapon` 仅在真实兵器招架时执行原比较：
`random(攻击武器 weight()/500 + rigidity + 先天 str)` 与防守方同式确定值比较。
大于两倍防守值脱手，大于防守值仅提示震动，大于防守值一半且非自制兵器则折损；
其他情况仅显示碰撞。该效果仅作用于注册了此回调的动作。
`throw_weapon` 仍每次消耗一枚，最后一枚先卸装、再由组合物品生命周期销毁。

## 防守属性归属

- `COMBAT_D->do_attack()` 的额外闪避使用防守方 `victim->query("dex")`，
  保留 `(dex - 10) / 4 + 2 > random(100)` 的整数计算与严格大于判断。
  这是常规命中、招架判定之后的伤害清零分支，不是角色总闪避率，也不改动原攻击结果码。
- 普通攻击的 `wounded` 和 `do_damage()` 的 `wound` 均使用防守方的
  `query("con")`，保留 `wound -= wound * (con - 10) / 100`。
  根骨在这两处减轻创伤（`eff_qi` 损失），不直接降低当次气血伤害。
- 上述两项使用先天基础字段，不计 `query_dex()` / `query_con()` 返回的装备或临时加成。

## 指定武学

### 反击、加力与互搏

- 趁隙反击在出手时读取防守方的 `query_temp("weapon")`，不读取持久属性中的
  `weapon`；空手、主手变更及副手转正均沿当前装备动作结算。
- `do_damage()` 的远程与近程分支先计算 `damage_bonus`，再统一加到伤害中。
  远程仍保留原来的加力消耗与不经过近程内功抵抗的规则，不新增抵抗或倍率。
- 左右互搏暂存首招的原始 `busy/interrupt`，不调用取消回调，也不重新应用忙乱减免。
  第二招失败或数值忙乱较短时恢复首招，较长时保留第二招。
  首招为函数型持续动作时不再执行第二招；第二招产生函数型动作时保留其回调。
  `feature/action.c` 的 `suspend_busy()` / `restore_busy()` 仅保存恢复状态，
  不用于替代正常动作完成或中断处理。

### 消耗与效果

- 盘古七势「开天辟地」、撼山锤法「撼山震岳」统一要求当前内力至少 500。
  命中扣 500、自忙 3；未中扣 300、自忙 4；持器、领悟、伤害和其他门槛不变。
- 十八罗汉棍阵使用 `apply/str`、`apply/dex`，增量仍为
  `((双方罗汉棍法之和)/10 + 双方有效膂力之和)/5`，上限 20。
  双方各扣精力 100、内力 300，自忙 1，共同敌人忙乱 `增量/3`。
  `receive_damage()` 只接收 `qi/jing`，所以精力、内力使用 `add()` 正常扣除。
- 双方共享一次组阵的 `gunzhen` 状态。每秒检查脱战、死亡/昏迷、离开、无棍或激发变化，
  清理仅撤销该次增量；重复或过期回调不能扣除其他加成、不能破坏新阵。
